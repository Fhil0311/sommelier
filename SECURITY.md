# Security

Sommelier installs and runs software on people's Macs. A security problem here is worse than an ordinary bug.

Report one privately, never in a public issue: use GitHub's "Report a vulnerability" on this repository, or write to
support@playsommelier.com. Include what you found, the steps to reproduce it and the version you used. You'll hear
back within a week; please give us time to fix it before telling others.

Examples: a download used without checking its pinned SHA-256; a game, store, mod or web page reaching files or code
outside its Wine environment; store login tokens written to logs or readable by other accounts; a way for another
build or a server to pass itself off as an official update; Apple software or someone's private data ending up in a
build or in this repository.
