# The Sommelier name and logo

The code is free under its license; the name and the grape logo are not. They tell players that a build comes from
the Sommelier project, is signed by it and updates from it.

**You may**, without asking: build and use the code yourself; share changes as patches or pull requests; write about
Sommelier and link to it; say that your project is "based on Sommelier" or "a fork of Sommelier".

**A version you distribute** (a fork, a rebuild, a package) must use its own name and icon, its own bundle identifier,
and its own update channel and signing key, so nobody takes it for the project's build. Don't use the name or logo in
a way that suggests the project endorses you.

Questions: support@playsommelier.com.
